# Hi, I'm Ross McNeely 👋

**Director, Data Engineering at [phData](https://www.phdata.io)** · Data & AI architect · Lakeville, MN

I've spent 15+ years building data, analytics, and AI platforms for enterprise and Fortune 500 organizations in healthcare, manufacturing, retail, and financial services. These days most of my time goes to **AI-assisted engineering**: using agentic tooling to modernize legacy data platforms faster and more reliably.

---

### 🔭 What I'm working on

- **Agentic migration tooling.** I build reusable "Skills" for Snowflake Cortex Code CLI that raised a code-migration agent's success rate from **50% to 80%** across hundreds of Azure Data Factory pipelines.
- **AI-assisted platform modernization.** I'm leading the translation of **2,100+ legacy SQL Server** stored procedures, tables, and views to Snowflake + dbt, with the architecture diagrams, test plans, and reusable migration standards that go with it.
- **Enterprise AI architecture.** I design multi-platform AI Centers of Excellence on AWS Bedrock, Microsoft Foundry, and local endpoint models, including tiered-latency telemetry strategies for global manufacturing.

### 🧠 Things I've built along the way

- Real-time IoT ingestion at **350M events/hour** from 55K devices using Kafka and Snowflake (a Digital Twin architecture)
- A **2-petabyte** Azure data platform (Data Lake, Data Factory, Databricks, Power BI) processing 300 GB per day
- Azure-to-AWS Databricks migrations with MLOps-based claims fraud detection
- Power BI Premium Centers of Excellence for multi-hospital health systems
- Epic Caboodle data warehouse integrations and population-health measures (HEDIS, MN Community Measures)
